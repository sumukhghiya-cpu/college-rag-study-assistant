SEMESTER OVERVIEW: The B.Tech CSE student's subjects in the uploaded syllabus documents are: Discrete Mathematics (code BAS 007B, 3-0-0 [3] credits), Python Programming (code BCO 081C, 2-0-4 [2] credits), Operating Systems (code BCO 008B, 3-0-0 [3] credits), Software Engineering (code BCO001B, 3-0-0 [3] credits), and Computer Networks (code BCO 011A, 3-1-0 [4] credits, B.Tech CSE Semester III). Every subject has 5 units.

ASSIGNMENTS OVERVIEW: Assignments were provided only for Python Programming (BCO 081C, B.Tech CSE (AIDS) Semester III). There are 3 assignments and each is worth 64 marks. Section-A has 5 short questions of 2 marks each (10 marks). Section-B has 3 questions of 7 marks each (21 marks). Section-C has 3 long questions of 11 marks each (33 marks). Assignment 1 covers Unit 1 (basics, control flow, loops, functions and scope). Assignment 2 covers Unit 2 (lists, tuples, dictionaries, sets, list comprehension, file handling). Assignment 3 covers Unit 3 (NumPy). No due dates are mentioned in the assignment documents.

DISCRETE MATHEMATICS (BAS 007B), 3-0-0 [3]. Objectives: to introduce a number of Discrete Mathematical Structures (DMS) that serve as tools in the development of theoretical computer science; to solve problems that occur in the development of programming languages; to familiarize students with concepts and techniques of graph theory, and sets apart from languages of logic and proof methods. Course outcomes: CO1 demonstrate complete knowledge of various discrete structures available in literature; CO2 realize that discrete structures are useful in computer science and engineering; CO3 gain confidence in dealing with problems that may arise in computer science and engineering in the near future.

DISCRETE MATHEMATICS (BAS 007B), UNIT 1: Sets: definition and types, set operations, partition of a set, cardinality (Inclusion-Exclusion and Addition Principles), recursive definition of a set. Functions: concept, some special functions (polynomial, exponential and logarithmic, absolute value, floor and ceiling, mod and div functions), properties of functions, cardinality of infinite sets, countable and uncountable sets.

DISCRETE MATHEMATICS (BAS 007B), UNIT 2 (part 1): Graph Theory: graphs - directed, undirected, simple; adjacency and incidence; degree of a vertex; subgraph; complete graph; cycle and wheel graph; bipartite and complete bipartite graph; weighted graph; union of simple graphs; isomorphic graphs; path, cycles and circuits; Eulerian and Hamiltonian graphs.

DISCRETE MATHEMATICS (BAS 007B), UNIT 2 (part 2): Planar graph: Kuratowski's two graphs, Euler's formula, Kuratowski's theorem. Trees: spanning trees, Kruskal's algorithm, finding a spanning tree using Depth First Search and Breadth First Search, complexity of graph algorithms, minimal spanning tree.

DISCRETE MATHEMATICS (BAS 007B), UNIT 3: Semigroups, Groups and Coding: binary operations, semigroups, products and quotients of semigroups, groups, products and quotients of groups, coding of binary information and error correction, decoding and error correction. Language of Logic: proposition, compound proposition, conjunction, disjunction, implication, converse, inverse and contrapositive, biconditional statements, tautology, contradiction and contingency, logical equivalences, quantifiers, arguments.

DISCRETE MATHEMATICS (BAS 007B), UNIT 4: Proof Methods: vacuous, trivial, direct, indirect (by contrapositive and contradiction), constructive and non-constructive proof, counterexample. The Division Algorithm, divisibility properties (prime and composite numbers), Principle of Mathematical Induction, the Second Principle of Mathematical Induction, Fundamental Theorem of Arithmetic. Algorithm Correctness: partial correctness, loop invariant, testing the partial correctness of linear and binary search, bubble sort and selection sort.

DISCRETE MATHEMATICS (BAS 007B), UNIT 5: Relations: Boolean matrices, binary relation, adjacency matrix of a relation, properties of relations, operations on relations, connectivity relations, transitive closure and Warshall's algorithm, equivalence relations, congruence relations, equivalence class, number of partitions of a finite set, partial and total orderings.

PYTHON PROGRAMMING (BCO 081C), 2-0-4 [2]. Objectives: to study core programming basics including data types, control structures and algorithm development; to overview the applications of Python; to become familiar with program design with functions; students will solve problems, explore real-world software development challenges and create practical and contemporary applications. Course outcomes: CO1 apply Python programming constructs to solve real-world problems; CO2 use Python data structures to manage and manipulate data; CO3 implement NumPy for efficient data processing; CO4 implement Pandas for efficient data processing; CO5 visualize data using Matplotlib and Seaborn for data-driven insights. Text book: Introduction to Python Programming by Gowrishankar S. and Veena A., CRC Press (Taylor and Francis). Reference book: Python: Real World Machine Learning by Prateek Joshi et al., Packt Publishing.

PYTHON PROGRAMMING (BCO 081C), UNIT 1: Introduction to Python Programming: Python syntax and indentation, variables, data types and typecasting, input/output operations, control flow (if-else, loops), functions and scope.

PYTHON PROGRAMMING (BCO 081C), UNIT 2: Data Structures in Python: lists, tuples, dictionaries and sets, list comprehensions, string manipulation, basic file handling (read/write CSV and text files).

PYTHON PROGRAMMING (BCO 081C), UNIT 3: Introduction to NumPy: arrays and array operations, indexing and slicing, array manipulation, mathematical and statistical operations.

PYTHON PROGRAMMING (BCO 081C), UNIT 4: Data Analysis with Pandas: Series and DataFrame creation, reading data from CSV files, data cleaning (handling missing values, renaming, dropping columns), data aggregation and grouping.

PYTHON PROGRAMMING (BCO 081C), UNIT 5: Data Visualization with Matplotlib and Seaborn: line, bar, pie and histogram plots, boxplots, scatter plots and heatmaps, basic customization of plots (titles, labels, legends).

OPERATING SYSTEMS (BCO 008B), 3-0-0 [3]. Objectives: to understand the structure and functions of an OS; to learn about processes, threads and scheduling algorithms; to understand the principles of concurrency and deadlocks; to learn various memory management schemes; to study I/O management and file systems. Course outcomes: CO1 classify Unix kernel mode with user mode and contrast kernel structures; CO2 identify and estimate process management and thread management strategies with their operations; CO3 implement different system calls for file handling operations; CO4 determine paging and caching techniques related to virtual memory.

OPERATING SYSTEMS (BCO 008B), UNIT 1: Introduction: operating system and its functions, classification of operating systems (batch, interactive, time sharing, real time, multiprocessor, multiuser, multiprocess, multithreaded systems), operating system structure (layered structure), system components, operating system services, monolithic and microkernel systems.

OPERATING SYSTEMS (BCO 008B), UNIT 2: Process Management: processes and threads, process states, Process Control Block, process scheduling, operations on processes, threads, CPU scheduler (preemptive and non-preemptive), dispatcher, scheduling criteria, scheduling algorithms, process management in UNIX.

OPERATING SYSTEMS (BCO 008B), UNIT 3: Process Synchronization and Inter Process Communication: concurrent processes, co-operating processes, precedence graph, hierarchy of processes, critical section problem, two process solution, synchronization hardware, semaphores. Deadlock: detection, handling, prevention, avoidance, recovery, starvation. Critical regions, monitors, inter process communication.

OPERATING SYSTEMS (BCO 008B), UNIT 4: Memory Management: objectives and functions, simple resident monitor program (no design), overlays, swapping, schemes (paging - simple and multi-level), internal and external fragmentation, virtual memory concept, demand paging, page interrupt, page fault, page replacement algorithms, segmentation (simple, multi-level, segmentation with paging), memory management in UNIX.

OPERATING SYSTEMS (BCO 008B), UNIT 5: I/O Management and Disk Scheduling: I/O devices, I/O subsystems, I/O buffering, disk storage and disk scheduling. File System: file concept, file organization and access mechanism, file directories, file sharing, file system implementation issues, file system protection and security.

SOFTWARE ENGINEERING (BCO001B), 3-0-0 [3]. Objectives: to learn about generic models of the software development process; to understand fundamental concepts of requirements engineering and analysis modeling; to understand different design techniques and their implementation; to learn various testing and maintenance measures.

SOFTWARE ENGINEERING (BCO001B), UNIT 1: Introduction: introduction to software engineering, software components, software characteristics, software crisis, engineering aspects of software production, necessity of automation, job responsibilities of programmers and software engineers as software developers, Software Development Life Cycle (SDLC).

SOFTWARE ENGINEERING (BCO001B), UNIT 2: Process Models and Program Design Techniques: software development process models (Code and Fix, Waterfall, Incremental, Rapid Prototyping, Spiral/Evolutionary), Software Requirement Specifications (SRS), management of user needs, Data Flow Diagrams, Entity Relationship Diagrams, decision tables, SRS document. Design techniques: structured programming, coupling and cohesion, abstraction and information hiding, software modeling tools (Data Flow Diagrams, UML and XML).

SOFTWARE ENGINEERING (BCO001B), UNIT 3: Software Testing: testing objectives, unit testing, integration testing, acceptance testing, regression testing, verification and validation, testing of software products, black-box testing and white-box testing, static analysis, symbolic execution, control flow graphs, cyclomatic complexity.

SOFTWARE ENGINEERING (BCO001B), UNIT 4: Software Project Management: management functions and processes, project planning and control, organization and intra-team communication, risk management. Software cost estimation: underlying factors of critical concern, metrics for estimating cost (Function Points), techniques for cost estimation (expert judgment, Work Breakdown Structure, Process Breakdown Structure, COCOMO and COCOMO-II).

SOFTWARE ENGINEERING (BCO001B), UNIT 5: Software Maintenance: need for maintenance, categories of maintenance, an overview of CASE tools.

COMPUTER NETWORKS (BCO 011A), 3-1-0 [4], B.Tech CSE Semester III. Objectives: to build an understanding of the fundamental concepts of computer networking; to familiarize students with the basic taxonomy and terminology of the computer networking area; to introduce advanced networking concepts, preparing students for entry into advanced courses; to allow students to gain expertise in specific areas of networking such as design and maintenance of individual networks. Course outcomes: CO1 in-depth understanding of terminology and concepts of the OSI reference model and TCP/IP model; CO2 technical concepts of protocols, network interfaces and design/performance issues; CO3 familiarity with contemporary issues in networking technologies; CO4 familiarity with network tools and analytical skills to develop innovative solutions.

COMPUTER NETWORKS (BCO 011A), UNIT 1 (part 1): Introduction: hardware and software, data communication, networking, protocols and standards, data transmission concepts, analog and digital transmission, transmission impairments, layered architecture of computer networks, OSI and TCP/IP architectures. Physical Layer: guided transmission media and wireless transmission, data encoding (digital and analog data), data communication interface, asynchronous and synchronous transmission.

COMPUTER NETWORKS (BCO 011A), UNIT 1 (part 2): Data link layer: flow control, error detection and error control, HDLC and other data link protocols. Multiplexing: frequency-division, synchronous time-division and statistical time-division multiplexing.

COMPUTER NETWORKS (BCO 011A), UNIT 2: Link Layer: Medium Access Control (CDMA, ALOHA, Ethernet), link layer addressing and forwarding, spanning trees, the channel allocation problem, multiple access protocols, Ethernet, wireless LANs, broadband wireless, Bluetooth, data link layer switching. Switched networks: circuit-switched networks, switching concepts, routing in circuit-switched networks, control signaling, packet switching principles, routing and congestion control.

COMPUTER NETWORKS (BCO 011A), UNIT 3: Network Layer: network layer design issues, routing algorithms (flooding, shortest path routing, link state routing, hierarchical routing, broadcast and multicast routing), routing in the Internet, path vector routing, OSPF routing. The network layer in the Internet: IP protocol, ARP and RARP, BOOTP, ICMP, DHCP, Network Address Translation (NAT).

COMPUTER NETWORKS (BCO 011A), UNIT 4: Transport Layer: TCP introduction, reliable and unreliable transport, TCP, UDP, congestion control, intra-domain routing (distance-vector, link-state), wireless networks, 802.11 MAC, efficiency considerations.

COMPUTER NETWORKS (BCO 011A), UNIT 5: Application Layer: DNS (the Domain Name System), electronic mail, HTTP, FTP, Simple Network Management Protocol (SNMP), the World Wide Web.
